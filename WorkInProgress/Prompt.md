# 🤖 Prompt.md

## 20 Prompts para Explorar IA Generativa no Universo Mainframe

### 📖 Introdução

Este documento expande o desafio proposto pela DIO, demonstrando como a Engenharia de Prompt pode ser utilizada para resolver problemas reais, criar conteúdo técnico, acelerar aprendizado e apoiar profissionais que atuam no ecossistema Mainframe.

Cada prompt utiliza a estrutura:

- Objetivo
- Contexto
- Formato
- Restrições
- Critério de Qualidade

------

# 🚀 Prompt 01 - Aprender JCL

Atue como um instrutor IBM Mainframe.

Crie um guia para iniciantes explicando os conceitos fundamentais de JCL.

Utilize exemplos comentados.

Compare comandos JCL com tarefas equivalentes em Linux.

Evite linguagem excessivamente técnica.

------

# 🚀 Prompt 02 - Entender JES2

Atue como um operador Mainframe experiente.

Explique o funcionamento do JES2 utilizando analogias do cotidiano.

Inclua exemplos de mensagens $HASP encontradas em produção.

Apresente dicas para interpretação de erros.

------

# 🚀 Prompt 03 - Aprender COBOL Moderno

Atue como um especialista COBOL.

Explique quais recursos modernos foram incorporados ao COBOL nas últimas décadas.

Compare COBOL com Java, Python e C#.

Inclua exemplos de código comentados.

------

# 🚀 Prompt 04 - Criar Laboratórios Práticos

Atue como um instrutor técnico.

Crie 10 laboratórios práticos para estudantes de z/OS.

Cada laboratório deve possuir:

- Objetivo
- Passo a passo
- Resultado esperado
- Possíveis erros

------

# 🚀 Prompt 05 - Traduzir Linguagem Técnica

Atue como um professor.

Explique o conceito de VSAM para uma criança de 12 anos.

Utilize exemplos simples.

Evite siglas sem explicação.

------

# 🚀 Prompt 06 - Simular Entrevista Mainframe

Atue como recrutador especializado em Mainframe.

Realize uma entrevista simulada para vaga de Programador COBOL.

Faça perguntas progressivas.

Ao final apresente avaliação técnica.

------

# 🚀 Prompt 07 - Diagnóstico de ABEND

Atue como analista de suporte Mainframe.

Explique as possíveis causas dos seguintes ABENDs:

- S0C7
- S806
- S222
- SB37

Apresente sintomas, diagnóstico e solução.

# 🎯 Conclusão

O verdadeiro objetivo destes prompts não é apenas gerar respostas.

Eles demonstram como a IA pode atuar como:

- Professor
- Mentor
- Arquiteto
- Operador
- Analista
- Recrutador
- Especialista Técnico

Quanto mais contexto, restrições e critérios de qualidade forem fornecidos, maior será a capacidade da IA de produzir resultados úteis, consistentes e alinhados ao objetivo desejado.

A Engenharia de Prompt é, na prática, uma extensão da Engenharia de Requisitos aplicada à Inteligência Artificial.
