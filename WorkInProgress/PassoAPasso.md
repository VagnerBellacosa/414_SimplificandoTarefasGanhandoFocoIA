# 🚀 Desafio Criativo DIO – Guia Completo de Conclusão

## 📖 Introdução

Este desafio tem como objetivo ensinar os fundamentos da Engenharia de Prompt, mostrando como transformar uma ideia simples em uma instrução clara e objetiva para uma Inteligência Artificial.

Embora a atividade pareça simples, ela desenvolve uma habilidade extremamente valorizada no mercado: a capacidade de estruturar requisitos, definir objetivos e comunicar expectativas de forma precisa.

------

# 🎯 Objetivo do Exercício

Construir um Prompt Final capaz de orientar uma IA a produzir exatamente o conteúdo desejado.

O desafio é dividido em três etapas:

1. Definir a intenção.
2. Adicionar contexto e restrições.
3. Consolidar tudo em um Prompt Final.

------

# 📝 Passo 1 – Defina a Intenção

Nesta etapa você deve responder três perguntas:

- O que deseja gerar?
- Para quem?
- Qual o resultado esperado?

## Exemplo Simples

```text
Quero que a IA gere um artigo sobre Mainframe para estudantes iniciantes, com o objetivo de apresentar os conceitos básicos da plataforma.
```

## Dica Profissional

Evite pedidos genéricos.

❌ Ruim:

```text
Explique Mainframe.
```

✅ Melhor:

```text
Explique Mainframe para estudantes de tecnologia que nunca tiveram contato com IBM z/OS.
```

Quanto mais específico for o objetivo, melhor será a resposta da IA.

------

# 📝 Passo 2 – Adicione Contexto e Restrições

Agora informe à IA como a resposta deve ser construída.

## Perguntas Importantes

- Em qual cenário o conteúdo será utilizado?
- Qual formato deseja receber?
- Existe algo que deve ser evitado?

## Exemplo

```text
Considere o contexto de treinamento corporativo para novos profissionais de tecnologia.

O conteúdo deve possuir formato de tutorial passo a passo.

Evite linguagem excessivamente técnica.
```

## Dica Profissional

As restrições são tão importantes quanto as instruções.

Exemplos:

- Evite termos sem explicação.
- Não utilize linguagem acadêmica.
- Limite a resposta a 1000 palavras.
- Inclua exemplos práticos.
- Utilize analogias do cotidiano.

------

# 📝 Passo 3 – Construa o Prompt Final

Agora una todas as informações em uma única instrução.

## Exemplo

```text
Quero que a IA gere um artigo para estudantes iniciantes em Mainframe, com o objetivo de apresentar os conceitos básicos da plataforma.

Considere o contexto de treinamento corporativo para novos profissionais de tecnologia.

O conteúdo deve possuir formato de tutorial passo a passo com exemplos comentados.

Evite linguagem excessivamente técnica e utilize analogias simples para facilitar o aprendizado.
```

------

# ⭐ Como Melhorar o Prompt

A estrutura da DIO é excelente para iniciantes, mas pode ser expandida.

Uma abordagem mais profissional utiliza sete componentes:

## 1. Objetivo

O que deseja obter?

```text
Criar um tutorial sobre JCL.
```

## 2. Público

Para quem?

```text
Programadores iniciantes.
```

## 3. Contexto

Onde será utilizado?

```text
Curso de formação Mainframe.
```

## 4. Papel da IA

Quem a IA deve representar?

```text
Atue como um especialista IBM Mainframe com 30 anos de experiência.
```

## 5. Formato

Como deve responder?

```text
Tutorial dividido em tópicos.
```

## 6. Restrições

O que evitar?

```text
Evite jargões não explicados.
```

## 7. Critério de Qualidade

Como medir o sucesso?

```text
Inclua exemplos reais e analogias práticas.
```

------

# 💡 Exemplo Avançado

```text
Atue como um especialista IBM Mainframe e instrutor técnico.

Crie um artigo para estudantes iniciantes em z/OS.

Objetivo:
Ensinar os fundamentos do JCL.

Contexto:
Treinamento corporativo para novos profissionais.

Formato:
Tutorial dividido em tópicos.

Restrições:
Evite linguagem excessivamente técnica.

Critério de Qualidade:
Inclua exemplos comentados, boas práticas e analogias com sistemas Linux.
```

# 📂 Como Entregar

## Opção 1 – Google Drive

1. Crie um arquivo .txt ou .md.
2. Salve o Prompt Final.
3. Faça upload para o Google Drive.
4. Clique em Compartilhar.
5. Configure como:
   - Qualquer pessoa com o link.
6. Copie o link.
7. Cole na plataforma da DIO.

------

## Opção 2 – GitHub

1. Crie um repositório público.
2. Crie um arquivo README.md.
3. Adicione seu Prompt Final.
4. Faça commit das alterações.
5. Copie a URL do repositório.
6. Envie na plataforma da DIO.

------

# 🏆 Diferencial Para Impressionar Avaliadores

Em vez de entregar apenas o Prompt Final, inclua uma breve reflexão sobre o que aprendeu.

Exemplo:

> Aprendi que um prompt funciona como uma especificação funcional para uma Inteligência Artificial. Quanto maior a clareza da intenção, contexto e restrições, mais previsível e útil será o resultado produzido.

Essa reflexão demonstra compreensão do conceito e maturidade técnica além do solicitado.
