# 🚀 Desafio Criativo: Simplificando Tarefas e Ganhando Foco com IA

## 📖 Sobre o Desafio

Este desafio tem como objetivo apresentar os conceitos fundamentais da **Engenharia de Prompt (Prompt Engineering)**, mostrando como estruturar instruções claras para obter melhores resultados utilizando Inteligência Artificial.

Ao longo da atividade, você aprenderá a transformar uma ideia genérica em uma solicitação detalhada, capaz de orientar uma IA a produzir exatamente o conteúdo desejado.

Mais do que criar um simples prompt, este exercício desenvolve uma habilidade essencial para profissionais de tecnologia: **a capacidade de definir objetivos, fornecer contexto e comunicar requisitos de forma clara e eficiente.**

------

# 🎯 Objetivo

Criar um **Prompt Final** que combine:

- Intenção
- Público-alvo
- Contexto
- Restrições
- Formato desejado

Ao final, você terá uma instrução completa e estruturada para utilização em ferramentas de IA Generativa.

------

# 🛠️ O Que Você Deve Fazer

O desafio está dividido em três etapas.

## Passo 1 – Definir a Intenção

Nesta etapa você deve responder:

- O que deseja que a IA faça?
- Para quem será o conteúdo?
- Qual resultado espera obter?

### Exemplo

```text
Quero que a IA gere um artigo para estudantes iniciantes em programação, com o objetivo de ensinar lógica de programação.
```

------

## Passo 2 – Adicionar Contexto e Restrições

Agora você deve informar:

- Em qual cenário o conteúdo será utilizado?
- Qual formato deseja receber?
- O que a IA deve evitar?

### Exemplo

```text
Considere o contexto de um curso introdutório de programação.

O conteúdo deve ter formato de tutorial passo a passo.

Evite termos excessivamente técnicos.
```

------

## Passo 3 – Criar o Prompt Final

Nesta etapa você unirá todas as informações em uma única instrução.

### Exemplo

```text
Quero que a IA gere um artigo para estudantes iniciantes em programação, com o objetivo de ensinar lógica de programação.

Considere o contexto de um curso introdutório.

O conteúdo deve ter formato de tutorial passo a passo.

Evite linguagem excessivamente técnica.
```

------

# 💡 O Que Está Sendo Aprendido na Prática?

Embora o desafio fale sobre IA, ele também ensina conceitos utilizados diariamente em diversas áreas da tecnologia:

- Engenharia de Requisitos
- Análise de Sistemas
- Arquitetura de Software
- Gestão de Projetos
- Documentação Técnica
- Comunicação Técnica

Um bom prompt segue a mesma lógica de uma boa especificação funcional:

```text
Objetivo
+
Contexto
+
Restrições
=
Resultado Melhor
```

Quanto mais claras forem as instruções, mais previsível e útil será a resposta da IA.

------

# ⭐ Como Criar um Prompt Ainda Melhor

Além da estrutura básica do desafio, você pode enriquecer seu prompt adicionando:

## Papel da IA

```text
Atue como um especialista IBM Mainframe.
```

## Formato de Resposta

```text
Responda em formato de tutorial.
```

## Critério de Qualidade

```text
Inclua exemplos práticos e analogias simples.
```

## Restrições Adicionais

```text
Evite termos técnicos sem explicação.
```

------

# 📋 Exemplo de Prompt Avançado

```text
Atue como um especialista IBM Mainframe e instrutor técnico.

Crie um artigo para estudantes iniciantes em z/OS.

Objetivo:
Explicar os fundamentos do JCL.

Contexto:
Treinamento corporativo para novos profissionais.

Formato:
Tutorial dividido em tópicos.

Restrições:
Evite jargões não explicados.

Critério de qualidade:
Inclua exemplos comentados, analogias com Linux e curiosidades históricas.
```

# 📤 Como Entregar

## Opção 1 – Google Drive

1. Crie um arquivo `.txt` ou `.md`.
2. Salve seu Prompt Final.
3. Faça upload para o Google Drive.
4. Clique em **Compartilhar**.
5. Selecione **Qualquer pessoa com o link**.
6. Copie a URL gerada.
7. Envie na plataforma da DIO.

------

## Opção 2 – GitHub

1. Crie um repositório público.
2. Crie um arquivo `README.md`.
3. Adicione seu Prompt Final.
4. Faça commit das alterações.
5. Copie a URL do repositório.
6. Envie na plataforma da DIO.
